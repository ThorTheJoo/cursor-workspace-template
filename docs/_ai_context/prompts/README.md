# Prompt Library

Reusable, task-specific prompt instructions and constraints for AI-assisted workflows.

## Usage

Place prompt files here using: `[CATEGORY]_[TASK].md`

Examples: CODE_REVIEW_CHECKLIST.md, MIGRATION_STEPS.md, COMPONENT_SCAFFOLD.md

## Structure per File

1. Objective - What the prompt achieves.
2. Constraints - Boundaries the AI must respect.
3. Input Schema - What the user provides.
4. Output Schema - Expected format.
5. Example - Concrete input/output pair.

Per MDD V1.3, the `phases/` subdirectory holds phase execution plans for complex work.
