# Knowledge Base

Synthesized research summaries and canonical domain knowledge.

## Usage

- `*.yaml` / `*.json` files are Rank 1 (Constitutional) per V1.3 Authority Hierarchy.
- `*_SUMMARY.md` files are synthesized research.
- `governance/` holds the knowledge governance chain (PENDING_UPDATES, UPDATE_HISTORY, ROLLBACK_LOG).
- `schemas/` holds JSON Schema validation files.
- `versions/` holds version snapshots.
- `staging/` holds external data awaiting review before promotion to canonical.

Human approval required for all knowledge file modifications.
